The simple calculator app

A basic calculator application that performs fundamental arithmetic operations, including addition, subtraction, multiplication, and division.

Features
+ Addition +
- Subtraction -
* Multiplication  X
/ Division /
User-friendly interface
Instant calculation results
Input validation
Division-by-zero error handling

Requirements
Hardware
Android smartphone

Software
Windows or Android

Usage
Launch the calculator application.
Enter the first number.
Enter the second number.
Select an arithmetic operation:
+ Addition
- Subtraction
* Multiplication
/ Division
Click the Calculate button (or =).
View the result.

Supported Operations
Operation	Symbol	Example	Result
Addition	+	10 + 5	15
Subtraction	-	12 - 4	8
Multiplication	*	6 * 3	18
Division	/	20 / 5	4
Input
The calculator accepts:

Integer values (e.g., 10)
Decimal values (e.g., 10.5)
Arithmetic operators (+, -, *, /)
Output
The application displays the calculated result based on the selected operation.

Examples
Input:
First Number: 10
Operator: +
Second Number: 5

Output:
15
Input:
First Number: 8
Operator: *

Second Number: 7

Output:
56
Error Handling
Error Condition	Message
Empty input	Please enter valid numbers.
Non-numeric input	Invalid input.
Division by zero	Cannot divide by zero.

Fast execution
